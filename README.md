# Prem Raval - Personal Portfolio Website

Personal single-page web portfolio for **Prem Raval**, B.Tech Computer Engineering candidate at NMIMS Mukesh Patel School of Technology Management and Engineering (MPSTME), Mumbai.

## 🌟 Highlights & Features
- **Modern Glassmorphism UI**: Built with HTML5, CSS3 vanilla styling, and interactive JavaScript.
- **Responsive Mobile Navigation**: Fully optimized for mobile smartphones, tablets, and desktops.
- **Projects Showcase**: Interactive category filters for Major & Minor engineering projects.
- **Research Publication**: Direct article link to published paper *"Helping People with Disability: Recruitment for Disables"* in IJIRCCE (Vol. 11, Issue 4, April 2023).
- **Capabilities & Skills**: Categorized technical skills chips (Python, C++, Android SDK, Flutter, Unity, Deep Learning CNNs).
- **Personal Hobbies**: Subtle interest cards featuring Gaming and Travelling.

## 🚀 Live Local Server
To run locally:
```bash
python3 -m http.server 8085
```
Open `http://localhost:8085` in your browser.
